C++ Native SIMD Kernel

Pre-compiled with AVX2 instruction sets, bitboard move generators, and killer heuristic tables for blazing nodes-per-second throughput.

Universal Chess Interface (UCI)

Standardized UCI protocol support allows plug-and-play matches in Arena GUI, Cutechess, Banksia, or hosting automated 24/7 bots on Lichess.

📱

Zero-Lag USB & Wi-Fi Sync

Developer Quickstart

Get up and running with Astrion in three simple terminal commands.

bash — Astrion Interactive CLI
# 1. Clone repository & install dependencies
git clone https://github.com/Team-Auralis/Astrion.git && cd Astrion

# 2. Start the UCI Engine
python orion_uci.py

# 3. Launch Mobile Server & PWA
python orion_app_server.py --port 8000
